# Set up AI provider in OpenSentinel 

### 1. This are the AI providers avaliable for OpenSentinel
* [googleaistudio](https://aistudio.google.com/)

* [openai](https://openai.com/)

* [ollama](https://ollama.com/)

* [openrouter](https://openrouter.ai/)

Make sure you write the name exactly as you see in provider
### 2. Get your API key in these avaliable providers.

### 3. Select  your model as you like but that works with OpenSentinel (NO JSON responses)
